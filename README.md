## 🚀 프로젝트 소개

**두부월드 & 두부네 오락실**은 2000년대 감성의 싸이월드 미니홈피와 쥬니버 동물농장을 현대적인 감각으로 재해석한 **포켓몬 육성 메타버스 & 실시간 멀티게임 플랫폼**입니다.

- 🏡 **두부월드 미니홈피 (포켓농장)**: 나만의 아늑한 미니룸에서 포켓몬과 스티커를 360° 회전 및 3D 틸트로 자유롭게 꾸미고, BGM을 감상하며 1촌 이웃과 파도타기 소통을 즐길 수 있습니다.
- 🎮 **두부 오락실 (10종 멀티게임)**: 미니홈피에서 탭 하나로 포켓몬 3v3 배틀, 포켓 테트리스, 캐치마인드, 마피아, 라이어, 텔레스트레이션, 숫자야구, 스도쿠, 지뢰찾기, 워들 등 10종의 게임을 바로 즐길 수 있습니다.
- 💼 **사내 엑셀 스텔스 모드 (F2 / ESC)**: 직장이나 학교에서도 안전하게 즐길 수 있도록 완벽한 **Excel Incognito UI**와 긴급 보스키를 지원합니다.
- 🤖 **Google Gemini AI 지능형 봇 탑재**: 마피아 및 라이어 게임에서 실제 사람처럼 토론, 추리, 블러핑을 수행하는 AI 봇이 함께합니다.

## 🏡 두부월드 미니홈피 (포켓농장) 상세 기능

### 1. 🚪 진입 플로우 & 온보딩 위저드
- **첫 방문 (비회원)**: 접속 즉시 **포켓농장 개설 신고서 & 스타팅 포켓몬 분양(33종 라인업 + 5% 전설 포켓몬)** 화면이 메인으로 뜹니다.
- **기존 회원**: 접속 시 **두부월드 미니홈피가 첫 화면**으로 즉시 로드됩니다.

### 2. 🎨 자유도 100% 3D 미니룸 & 스티커 데코레이션
- **3D Perspective 캔버스**: 0°~360° 자유 평면 회전(`rotation`) 및 -60°~+60° 앞뒤 눕힘 틸트(`tiltX`), 좌우반전, 크기 스케일 조절 지원.
- **다양한 스티커 & 말풍선 제작기**: 30종 이상의 감성/이모지 스티커와 맞춤형 문구(클래식 말풍선, 우드 표지판, 네온 사이버, 핑크 리본, 골드 뱃지 등)를 원하는 위치에 자유롭게 배치.
- **보육소 & 졸업생 포켓몬 배치**: 파트너 포켓몬뿐만 아니라 보육소 친구들과 명예 졸업생들을 미니룸에 원하는 각도로 함께 배치 가능.

### 3. 🎵 BGM 주크박스 & 프로필
- 프리스타일 - Y, 쿨 - 아로하, 허밍어반스테레오 - Hawaiian Couple, 에픽하이 - Fly, 태초마을 BGM 등 추억의 명곡 플레이어 탑재.
- 실시간 **TODAY / TOTAL** 방문자 수 카운터 및 투데이 상태 메시지 편집.

### 4. 👥 이웃 파도타기 & 🏆 실시간 인기 농장 TOP 3
- **실시간 인기 농장 TOP 3 (하트 랭킹)**: 전체 유저 중 가장 많은 1촌 응원 하트(💖)를 받은 농장 명예의 전당 전시.
- **1촌 파도타기 & 방명록**: 다른 유저의 미니홈피에 방문하여 상대방의 3D 미니룸과 BGM을 감상하고, 1촌 하트 선물 및 방명록 작성.

### 5. 💼 육성, 알바, 탐험, 복권, 보육소, 졸업 시스템
- **🐾 팜 쓰다듬기 고유 스킬 모션**: 포켓몬 터치 시 점프 액션 및 속성별 고유 스킬(물대포, 불꽃세례, 10만볼트 등) 오라 버스트 발동.
- **💼 5종 아르바이트 현장 모션**: 화단 물주기(물/풀타입 스킬), 우편 배달(비행/에스퍼 스킬), 원두 로스팅(불타입), 발전소 가동(전기타입), CEO 경호.
- **🌲 사내 탐험 & 🥚 알 인큐베이터**: 탐험지(회사 뒷산, 포켓 동굴 등) 파견을 통해 코인/경험치/알 획득 후 데이케어 인큐베이터에서 온기를 모아 부화.
- **🎰 일일 럭키 복권 슬롯**: 매일 3회 무료 슬롯머신 스핀을 통해 잭팟 코인 및 희귀 열매 획득.
- **✨ 진화의 방 & 🎓 감동의 졸업식**: 최종 진화 후 Lv.36 달성 시 명예 학사모 졸업 증서 수여 및 도감 앨범 영구 기록.

## 💾 SQLite (`better-sqlite3`) 데이터베이스 아키텍처

- **고성능 파일 기반 SQL DB**: `server/data/pokefarm.db` (WAL 모드 적용으로 동시성 및 쓰기 속도 극대화).
- **자동 마이그레이션**: 기존 JSON 데이터 파일을 기동 시 SQLite 테이블로 무중단 자동 변환.
- **DB 테이블 구조**:
  - `farms`: 농장 기본 정보, 파트너/보육소/졸업생 포켓몬, 인벤토리, 미니룸 스티커 및 3D 배치 좌표, BGM, Today/Total 카운트
  - `guestbooks`: 유저 간 방명록 메시지 및 타임스탬프
  - `farm_hearts`: 유저 간 1촌 하트 전송 로그
- **RESTful API**: `GET /api/farms`, `GET /api/farms/popular`, `GET /api/farms/:username` 제공.

## 🧠 Google Gemini AI 엔진 (`server/src/aiService.js`)

- **경량 REST API 직결**: 무거운 SDK 없이 `axios`로 Google Gemini REST API(`gemini-3.6-flash`)를 직접 호출.
- **지능형 토큰 최적화**: 게임 대화에 최적화된 토큰 제한과 `thinkingBudget` 제어로 1~2초대 초고속 응답.
- **25초 쓰로틀링 & 429 Quota 방어**: 다중 봇 환경에서도 순차 스케줄링으로 무료 티어 API Rate Limit 원천 차단.
- **다단계 JSON 복구 파서**: 따옴표 중복, 생각 과정 잔여물 등을 실시간 감지하여 순수 한국어 대화로 복구.

## 🏎️ 실행 및 배포 방법

### 1. 환경변수 설정
`server/` 디렉토리에 `.env` 파일을 생성합니다:
```env
PORT=3001
ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173

# Google Gemini API 설정 (선택 사항: 미설정 시 기본 템플릿 봇으로 작동)
GEMINI_API_KEY=AIzaSyYourGeminiApiKeyHere
GEMINI_MODEL=gemini-3.6-flash
```

### 2. 로컬 개발 환경 실행

```bash
# 1. 백엔드 서버 실행
cd server
npm install
npm run dev

# 2. 프론트엔드 개발 서버 실행 (새 터미널, 프로젝트 루트)
npm install
npm run dev
```

### 3. Docker Compose 배포

```bash
docker compose up -d --build
```
- **프론트엔드 (Nginx)**: `http://localhost:80`
- **백엔드 (Socket.IO & API)**: `http://localhost:3001` (Nginx 역프록시 `/socket.io/`, `/api/` 경유)
